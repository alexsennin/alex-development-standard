# ALEX DEVELOPMENT STANDARD v1.3.1

Versión 1.3.1, 2026-10-06. Estado: **vigente y de adopción obligatoria para todo trabajo nuevo o activo bajo ALEX Development Standard**.

v1.3.1 endurece v1.3 sin añadir una metodología paralela: corrige vocabulario y autorización, reduce el contexto de runtime con [CORE.md](CORE.md), desacopla modelos comerciales al [MODEL_PROFILE](../../profiles/MODEL_PROFILE.md), añade escalamiento forzado, revisión independiente Nivel 4, Execution Packet y casos iniciales de calibración.

## Entrada
1. Leer [CORE.md](CORE.md).
2. Leer `AGENTS.md` del proyecto.
3. Usar la matriz de carga para abrir sólo documentos especializados pertinentes.

## Política de adopción
Los proyectos nuevos adoptan v1.3.1 desde el inicio. Los proyectos activos bajo ALEX Development Standard deben adoptarla explícitamente antes de su siguiente cambio sustantivo. No hay fase de piloto separada: la metodología se valida y ajusta con trabajo real.
